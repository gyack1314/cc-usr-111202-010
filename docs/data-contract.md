# 条件扫描资料

centers每行id唯一，expected为严格正有理数，observed为非负整数；expected只决定条件null概率，数量总和不必等于观察总数。edges为无向邻接关系，重复方向合并，孤立中心允许；自环和未知端点拒绝。radii是非负整数的公开集合，闭球按最短图距离定义。

每个候选区域用升序中心ID元组标识，观察排名同分按该元组比较。comparison_tolerance仅用于识别需精核的近似相等，不允许把任意相近但不等的统计量当成真正并列；小整数情形可用有理概率下的似然比幂积独立比较。draws是独立多项抽样次数，seed仅决定复现，不能选择性更换好看的种子。精确模式受exact_state_budget约束，不完整枚举不报告精确尾部。

domain仅核对邻接和合计，不建闭球族或进行扫描。

## 条件最大扫描口径（research_data.scan）

候选族只由edges与radii决定：对每个中心取各radius的图距离闭球，相同中心集合去重，空集与全体中心不参加检验；族在读取observed之前固定并保存SHA-256指纹，不允许事后按显著性裁剪。条件null固定总异常数N，计数向量服从概率正比于expected的多项分布，expected总和不必等于N。

区域统计量为单侧对数似然比，仅当区内计数c严格大于N*p（p为区内expected占比）时计算`c*log(c/(N*p))+(N-c)*log((N-c)/(N*(1-p)))`，否则取0，`0*log0`按0处理。每次null抽样都在全中心重分配N，再扫描完整固定候选族取最大统计量：主检验与每个区域的校正p值都对照同一份null最大值分布，公式为`(1+大于等于观察值的次数)/(B+1)`，禁止用单区域自身null尾部冒充校正。统计量同分按区域中心ID升序元组排序；comparison_tolerance只用于识别落入容差窗口、需要有理幂积（或高精度Decimal对数）精核的近似相等，精核不等就不得判并列，避免浮点误差排除真正并列。

精确模式枚举全部弱组合（状态数C(N+V-1,V-1)），每个计数向量按其真实多项概率（Fraction加权，阶乘按计数xi索引）计入尾部，绝不按向量等权；状态数超过exact_state_budget时拒绝报告精确尾部，auto模式回退蒙特卡洛并明确标注“抽样不是精确检验”。蒙特卡洛结果同时给出二项标准误差`sqrt(p(1-p)/(B+1))`与最小分辨率`1/(B+1)`，有限B的校正值是带误差的估计而非精确概率。numpy加速引擎与纯Python基准共用同一候选族、同一归一化概率向量，仅RNG流不同。N=0时所有统计量为0、所有p值为1；图上无任何有效候选区域（如单中心图）时状态为no_candidate_regions，单独报告且不执行检验。
